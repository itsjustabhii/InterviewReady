Before You Start

  • Start MongoDB: mongod (default port 27017)
  • Start Redis: redis-server (default port 6379)
  • Set real Razorpay test keys in Backend/.env and Frontend/.env
  • Backend: cd Backend && npm run dev → http://localhost:5000
  • Frontend: cd Frontend && npm run dev → http://localhost:5173
  • All /api/* requests are proxied by Vite — no CORS configuration needed in dev
